# GaeunMemo

Windows 바탕화면 스티커 메모. 버전마다 폴더가 따로 있고, 각 폴더는 그 버전을 그대로 빌드할 수 있는 전체 프로젝트다.

| 버전 | 폴더 | 내용 |
| --- | --- | --- |
| **1.1** | [`1.1/`](1.1/) | 1.0 + 전체화면(최대화)과 서식 도구 모음(굵게·기울임·밑줄·취소선·글머리 기호), 사진 넣기(붙여넣기·끌어다 놓기·버튼), 웹/워드 붙여넣기 서식 정리, 메모 잠금(본문 클릭 → 복사), 메모별 작업표시줄 미리보기, 자동 실행 항목 자동 복구, 시작 로그 |
| **1.0** | [`1.0/`](1.0/) | 첫 버전. 프레임 없는 메모 창, 접기·핀·색·띠 모양·다크/라이트, 메모 목록·검색, 트레이·자동 실행·단일 인스턴스, 자동 저장·백업 |

빌드: 원하는 버전 폴더의 `src-tauri`에서 `cargo tauri build` → `target/release/bundle/nsis/GaeunMemo_<버전>_x64-setup.exe`

두 버전은 같은 데이터(`%APPDATA%\gaeunmemo\notes.json`)를 쓴다. 1.1에서 서식을 넣은 메모를 1.0에서 열면 서식 없이 글자만 보인다(평문 사본을 함께 저장하기 때문).
